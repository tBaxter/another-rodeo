If you're messing with bikes for any amount of time, eventually you need a wheel truing stand. For quite a while now, I've been really happy with the now-discontinued [Park Tool TS-8](https://amzn.to/48BabnQ) with one exception: Park inexplicably cheaped out on the indicator that sits by the rim to show you if it's true or not.

Where better stands will have nice calipers for both sides of the wheel, the TS-8 shipped with a flat piece of steel that comes up to only one side of the wheel. This makes things more difficult for a couple of reasons. First, you can't bring the wheel to true by removing excess in both directions. Second, when it comes time to properly dish the wheel, it's a lot harder when you can't see the distance on both sides.

So I did something about it and printed this up:

  {% figure img_path "truing-stand.jpeg", "Much better" %}

  It bolts right up to the existing stand bracket using the stock bolt, and it completely transforms the stand for me. 

As usual, 
[the model is on MakerWorld](https://makerworld.com/en/models/2748543-truing-stand-caliper-upgrade).
